# Global-Electronics-Retail-Performace-Analysis
An end-to-end data analysis project exploring sales performance, profitability, and customer behavior for a global electronics retailer using SQL Server, Excel, and Power BI.

The goal is to identify business trends, evaluate profitability, and uncover opportunities to improve revenue and customer performance.

## Main Problem
This business analysis project aims to investigate how can a global electronics retailer increase profitability, improve sales performance, and make better inventory and customer decisions using historical sales data. Specifically, the projects aims to answer the following questions:
1. How do revenue and profit change over time?
2. Which product categories, brands, and countries generate the most revenue and profit?
3. Which products have high revenue but low profit margins?
4. Which products or segments generate losses?
5. How do customer demographics relate to purchasing behavior?
6. How much revenue comes from the highest-value customers?
